Zero Trust Secure Session Gateway - Demo Requirements
=====================================================

This document lists the requirements and setup instructions for running the demo.

System Requirements
------------------

1. **Operating System**
   - Linux (Ubuntu 20.04+, CentOS 8+, etc.)
   - macOS 10.15+
   - Windows 10+ (with WSL2 recommended)

2. **Build Tools**
   - CMake 3.28 or higher (for C++23 module support)
   - GCC 13+ or Clang 17+ (for C++23 support)
   - MSVC 19.34+ (Visual Studio 2022 17.4+) on Windows
   - Make 3.81 or higher
   - Git for version control

3. **Runtime Dependencies**
   - OpenSSL 1.1.1+ (for TLS and cryptography)
   - Boost 1.75+ (for asynchronous networking)
   - Python 3.8+ (for demo client)
   - curl (for testing with HTTP requests)
   - jq (for JSON processing in shell scripts)

4. **Optional Dependencies**
   - Docker 20.10+ (for containerized deployment)
   - Docker Compose 2.0+ (for full demo stack)
   - OpenSSL command-line tools (for certificate generation)

5. **Python Packages** (for demo client)
   - json (built-in Python 3.8+)
   - ssl (built-in)
   - socket (built-in)
   - argparse (built-in)
   - time (built-in)

Quick Setup Guide
-----------------

### Linux/macOS

```bash
# 1. Install build dependencies (Ubuntu/22.04+ for C++23 support)
sudo apt-get update
sudo apt-get install -y \
    build-essential cmake git \
    libboost-all-dev libssl-dev \
    python3 python3-pip curl jq

# 2. For C++23 support, you may need newer compilers:
# Ubuntu 22.04+ includes GCC 11, but for full C++23 support:
sudo add-apt-repository ppa:ubuntu-toolchain-r/test
sudo apt-get update
sudo apt-get install gcc-13 g++-13

# 3. Set GCC 13 as default
sudo update-alternatives --install /usr/bin/gcc gcc /usr/bin/gcc-13 100
sudo update-alternatives --install /usr/bin/g++ g++ /usr/bin/g++-13 100

# 4. Install Python demo dependencies
pip3 install --user -r examples/demo_requirements.txt

# 5. Clone and build
git clone <repository-url>
cd zero-trust-secure-session-gateway
chmod +x examples/demo_script.sh
./examples/demo_script.sh
```

### Windows (Native with Visual Studio 2022)

```powershell
# 1. Install Visual Studio 2022 17.4+ with C++ development tools
# Download from: https://visualstudio.microsoft.com/downloads/

# 2. Install vcpkg for package management
git clone https://github.com/Microsoft/vcpkg.git
cd vcpkg
.\bootstrap-vcpkg.bat
.\vcpkg integrate install

# 3. Install required packages via vcpkg
.\vcpkg install boostasio boostsystem openssl spdlog nlohmann-json yaml-cpp gtest

# 4. Build with CMake (from Developer Command Prompt)
mkdir build
cd build
cmake .. -DCMAKE_TOOLCHAIN_FILE=<vcpkg-root>/scripts/buildsystems/vcpkg.cmake
cmake --build . --config Release

# 5. Run demo
.\bin\Release\zerossg_gateway.exe --help
```

### Windows (WSL2)

```bash
# 1. Enable WSL2 and install Ubuntu 22.04+
wsl --install -d Ubuntu

# 2. In WSL2 Ubuntu, follow Linux instructions above
# Note: Ensure C++23 compatible compiler is installed
```

### Docker (Recommended for Easy Demo)

```bash
# 1. Install Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# 2. Install Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/download/v2.20.0/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose

# 3. Run demo
docker-compose up -d
```

Troubleshooting
---------------

### Common Issues and Solutions

**Issue**: "Port 8443 already in use"
**Solution**: 
```bash
# Kill existing process
sudo lsof -ti:8443 | xargs kill -9
# Or change port in config.json
```

**Issue**: "Certificate verification failed"
**Solution**:
```bash
# Regenerate demo certificates
cd examples && ./generate_certs.sh
# Or use -k flag with curl for demo
```

**Issue**: "Build failed with C++20 errors"
**Solution**:
```bash
# Check compiler version
g++ --version  # Should be 10+
# Or specify C++ standard explicitly
cmake .. -DCMAKE_CXX_STANDARD=20
```

**Issue**: "Python client can't connect"
**Solution**:
```bash
# Check if server is running
netstat -tulpn | grep :8443
# Test with curl first
curl -k https://localhost:8443
```

**Issue**: "Docker build fails"
**Solution**:
```bash
# Clean Docker cache
docker system prune -f
# Rebuild without cache
docker-compose build --no-cache
```

### Debug Mode

Security Validation
------------------

### Authentication Testing

```bash
# Test various invalid credentials
for user in "admin" "root" "test" "guest"; do
    for pass in "password" "123456" "admin" "test"; do
        curl -k -s -X POST https://localhost:8443 \
            -H "Content-Type: application/json" \
            -d "{\"type\":\"login\",\"username\":\"$user\",\"password\":\"$pass\"}" \
            | jq -r '.status'
    done
done
```

### Authorization Testing

```bash
# Test access without authentication
curl -k -s -X POST https://localhost:8443 \
     -H "Content-Type: application/json" \
     -d '{"type":"session","target_service":"database"}' \
     | jq -r '.message'
```

### Rate Limit Testing

```bash
# Send rapid requests to trigger rate limiting
for i in {1..200}; do
    curl -k -s -X POST https://localhost:8443 \
         -H "Content-Type: application/json" \
         -d '{"type":"login","username":"test","password":"wrong"}' \
         > /dev/null
done
```
